## Быстрый старт

Из корня репозитория:

```bash
cd frontend
npm install
npm run dev
```

Сборка для продакшена: `npm run build`, локальный превью билда: `npm run preview`.

Переменные окружения и URL API — см. раздел про запуск и `.env` в [корневом README](../README.md).
